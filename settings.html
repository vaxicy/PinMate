Getting Started

  1. 1
    Open Pinterest Create Pin
    Go to the Pinterest Create Pin page with an image ready.
  2. 2
    Set your API Key
    Choose a provider, enter your API Key & model, then test connection.
  3. 3
    Generate & insert
    Click generate to analyze the image, then fill title & description into Pinterest.

How to get API Key?

  1. 1
    Choose a provider
    Pick SiliconFlow (recommended in China) or OpenAI in the settings above.
  2. 2
    Get your API Key
    Sign up on the provider's site and create an API Key.
  3. 3
    Paste & test
    Return here, paste the Key and model, then click Test Connection.
