隐私权政策

最后更新：2026 年 7 月 24 日 | 生效日期：2026 年 7 月 24 日

一、概述

本隐私权政策说明 PinMate（以下简称「本扩展」）如何收集、使用和保护您的信息。使用本扩展即表示您同意本政策所述做法。

二、我们收集哪些信息

2.1 本扩展收集的信息

  • AI 配置设置：您在设置页面中自愿填写的 AI 服务商选择、API 地址、API 密钥（API Key）、模型名称、分析语言、生成语言。这些数据仅存储在您本地浏览器的扩展存储中。
  • Pinterest 页面内容：当您在 Pinterest 创建 Pin 页面点击「生成」时，本扩展会读取当前标签页中的图片元素，用于发送给 AI 进行分析。此操作仅在您主动点击时触发。

2.2 本扩展不收集的信息

  • 我们不收集您的个人身份信息（姓名、邮箱、电话等）。
  • 我们不收集您的浏览历史、书签或访问记录。
  • 我们不设置任何追踪器或分析代码。
  • 我们不会在后台静默访问任何网页或读取任何标签页内容。
重要提示：您的 API Key 是敏感凭据。本扩展仅将其保存在您本地浏览器中，不会传输给开发者或任何第三方服务器（仅发往您自己配置的 AI 服务接口）。请勿将您的 API Key 分享给他人。

三、信息如何使用

  • AI 配置数据：用于向您选择的 AI 服务商（硅基流动 / OpenAI / 自定义接口）发送图片分析和文本生成请求。
  • Pinterest 页面图片：作为输入发送给您配置的 AI 接口，以生成 SEO 标题和描述。
  • 所有网络请求均由您主动触发，本扩展不会自动或在后台发起任何请求。

四、第三方服务

本扩展需要连接以下第三方 AI 服务（由您自行选择和配置）：

  • 硅基流动（SiliconFlow） — api.siliconflow.cn
  • OpenAI — api.openai.com
  • 自定义 OpenAI 兼容接口 — 由您自行填写的地址

这些服务的使用受其各自的服务条款和隐私政策约束。我们不对第三方的数据处理行为负责。所有请求均使用您自己的 API Key 和账户发起。

五、数据存储与安全

  • 所有配置数据存储在您本地浏览器的 chrome.storage.local 中。
  • 数据不会上传到开发者的服务器。
  • 卸载本扩展后，所有本地存储的数据将被清除。
  • 建议您妥善保管自己的 API Key，不要在不信任的设备上使用。

六、您的权利

  • 您可以随时在扩展设置页修改或删除已保存的 AI 配置。
  • 您可以随时通过浏览器扩展管理页面卸载本扩展，这将删除所有本地存储的数据。
  • 如果您希望导出或查看存储的数据，可以通过浏览器开发者工具访问 chrome.storage.local。

七、儿童隐私

本扩展不面向 13 岁以下儿童。我们不会故意收集儿童的个人信息。

八、政策变更

如果我们更新本隐私权政策，我们将在此页面发布新版本并更新「最后更新」日期。重大变更将通过扩展内通知告知用户。

Privacy Policy

Last Updated: July 24, 2026 | Effective Date: July 24, 2026

1. Overview

This Privacy Policy explains how PinMate (the "Extension") collects, uses, and protects your information. By using this Extension, you agree to the practices described in this policy.

2. Information We Collect

2.1 Information Collected by the Extension

  • AI Configuration Settings: Your voluntarily entered AI provider choice, API base URL, API Key, model name, analysis language, and generation language from the settings page. This data is stored only in your local browser's extension storage.
  • Pinterest Page Content: When you click "Generate" on the Pinterest Create Pin page, the Extension reads the image element from the current tab for AI analysis. This action is triggered only by your explicit click.

2.2 Information We Do NOT Collect

  • We do not collect your personal identity information (name, email, phone, etc.).
  • We do not collect your browsing history, bookmarks, or visit records.
  • We do not use any trackers or analytics code.
  • We do not silently access any web pages or read any tab content in the background.
Important: Your API Key is sensitive credential information. The Extension stores it only in your local browser and never transmits it to the developer or any third-party server (it is only sent to the AI service endpoint you configured). Do not share your API Key with others.

3. How Information Is Used

  • AI Configuration Data: Used to send image analysis and text generation requests to your chosen AI provider (SiliconFlow / OpenAI / Custom endpoint).
  • Pinterest Page Images: Sent as input to your configured AI endpoint to generate SEO titles and descriptions.
  • All network requests are initiated by you manually. The Extension does not automatically or silently send any requests in the background.

4. Third-Party Services

This Extension connects to third-party AI services that you select and configure yourself:

  • SiliconFlow — api.siliconflow.cn
  • OpenAI — api.openai.com
  • Custom OpenAI-Compatible Endpoint — The address you provide

Use of these services is subject to their respective terms of service and privacy policies. We are not responsible for third-party data handling practices. All requests are made using your own API Key and account credentials.

5. Data Storage & Security

  • All configuration data is stored locally in your browser's chrome.storage.local.
  • Data is NOT uploaded to the developer's servers.
  • Uninstalling the Extension will delete all locally stored data.
  • Please keep your API Key secure and avoid using it on untrusted devices.

6. Your Rights

  • You may modify or delete saved AI configurations at any time via the Extension settings page.
  • You may uninstall the Extension at any time via your browser's extension management page, which will delete all locally stored data.
  • If you wish to export or view stored data, you can access chrome.storage.local via browser DevTools.

7. Children's Privacy

This Extension is not directed at children under 13. We do not intentionally collect personal information from children.

8. Changes to This Policy

If we update this Privacy Policy, we will post the new version on this page with an updated "Last Updated" date. Significant changes will be notified to users within the Extension.
