PinMate is an AI assistant for Pinterest creators. Upload an image and get SEO title, description, tagged topics, and alt text in seconds — filled into Pinterest's create form with one click.

🚀 Core Features
• One-click generation — analyzes your create-page image and produces SEO title, description, tagged topics, and alt text.
• AI-powered — multimodal vision models understand subject, style, and audience.
• Smart SEO — keywords and search context woven into title and description for better reach.
• Auto-fill — generated content drops straight into Pinterest fields, no copy-paste.
• Bilingual — switch UI and output language between Chinese and English on the fly.
• Flexible panel — floating panel works everywhere or only on the Create Pin page.
• Privacy-first — data stays local; API keys live in extension storage.

🤖 Multi-Provider · Key Pool with Auto Failover
Works with SiliconFlow, OpenAI, Google Gemini, and any OpenAI-compatible endpoint. Each provider keeps its own pool of API keys, base URL, and vision model — in auto mode a failing key is seamlessly swapped for the next, with cooldown to avoid burning bad keys.
⚠ No API key bundled. Bring your own key from at least one provider to start.

📖 How to Use
1. Install, open the Pinterest Create Pin page, and upload an image.
2. Click the extension icon → Settings, pick a provider, paste your API key and model, then hit Test Connection.
3. Click "Generate" on the floating panel, review results, then "Fill All".

🔒 Privacy
No personal data collected. API keys stay local; image and text generation go through the AI service you configure. The extension never uploads silently.
