一键生成 Pinterest 标题、描述、话题标签与替代文本；商品链接可开启粘贴即自动填入，并可自动勾选 Affiliate 声明。

=== 中文详细说明 ===

PinMate 是给 Pinterest 创作者的 AI 助手：上传一张 Pin 图片，AI 读懂画面后写出标题、描述、话题标签与替代文本，一键填入发布表单。

• 看图写文案 —— 贴合画面本身，不是套模板
• 一键填入 —— 标题、描述、标签、替代文本直接写进 Pinterest
• 商品链接：粘贴进面板后可选自动填入链接与产品标签，并可自动勾选 Affiliate link 声明
• 云端与本地模型都可以用 —— 用本地模型时图片不出本机
• 中英双语；密钥与设置只保存在你自己的浏览器里
• 内置使用教程，常见问题都有说明

在设置中填入自己的 API 密钥（或选择本地模型）即可开始。

=== English Summary (from _locales/en/messages.json) ===

One-click Pinterest titles, descriptions, tags and alt text — optional product-link auto-fill, affiliate disclosure included.

=== English Detailed Description ===

PinMate is an AI assistant for Pinterest creators: upload a Pin image and it reads the picture, then writes a matching title, description, topic tags and alt text — all filled into the publish form in one click.

• Written from the image itself — not a template
• One-click fill — title, description, tags and alt text go straight into Pinterest
• Product links: optional auto-fill once pasted, with the affiliate disclosure ticked for you
• Works with cloud and local models — with a local model your images never leave your machine
• English & Chinese UI; keys and settings stay in your browser
• Built-in guide covering setup and common issues

Add your own API key (or pick a local model) in Settings to start.
