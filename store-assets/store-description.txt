=== 中文详细说明 ===

PinMate 是给 Pinterest 创作者准备的 AI 助手。上传一张 Pin 图片，AI 会先读懂画面，再据此写出标题、描述和话题标签，并自动填入发布表单，省去逐字敲写的时间。

• 看图写文案 —— 内容贴合画面本身，不是套模板
• 一键填入 —— 结果直接写进 Pinterest，也可随时复制或重新生成
• 中英双语 —— 界面和生成结果都能随时切换语言
• 数据留在本地 —— 设置与密钥只存在你的浏览器里

在设置中填入自己的 API 密钥即可开始。

=== English Detailed Description ===

PinMate is an AI assistant built for Pinterest creators. Upload a Pin image and it studies the picture, writes a matching title, description and topic tags, then fills them straight into the publish form — no typing it all out by hand.

• Image-first copy — written from what's actually in the picture, not a template
• One-click fill — results go into Pinterest directly, and you can copy or regenerate them anytime
• Bilingual — switch the interface and the generated text between English and Chinese at any time
• Kept local — your settings and API keys stay in your browser

Add your own API key in Settings and you're all set.
