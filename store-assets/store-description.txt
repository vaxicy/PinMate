=== 中文详细说明 ===

PinMate 是 Pinterest 内容创作者的 AI 助手。上传图片，几秒内获得 SEO 标题、详细描述、话题标签和替代文本，一键填入 Pinterest 创建表单。

🚀 核心功能

• 一键生成 — 自动分析创建页图片，一键生成 SEO 标题、描述、Tagged topics 标签与 Alt Text。
• AI 驱动 — 多模态视觉模型理解图片主体、风格与受众，输出自然吸睛的文案。
• 智能 SEO — 标题与描述融入关键词和搜索场景，提升曝光与点击。
• 自动填入 — 生成内容一键写入 Pinterest 对应字段，无需复制粘贴。
• 多语言 — 界面中英实时切换，分析与输出语言可分别指定。
• 灵活面板 — 悬浮面板可拖拽，支持仅在创建页或全站显示。
• 隐私优先 — 数据本地留存，API Key 仅保存在浏览器扩展存储中。

📌 使用方法

1. 安装后打开 Pinterest 创建 Pin 页并上传图片。
2. 点击扩展图标 → 设置，选择 AI 服务商并填入 API Key。
3. 点击悬浮面板「一键生成」，查看结果后「全部填入」即可。

🤖 支持 SiliconFlow、OpenAI 及任意 OpenAI 兼容端点。

⚠️ 需自备所选服务商的 API Key，PinMate 不内置密钥。

🔒 隐私声明

PinMate 不收集个人数据。API Key 仅存本地，图片与文本生成通过你配置的 AI 服务完成，扩展不会静默上传数据。

💬 支持

欢迎通过 Chrome Web Store 评论或 GitHub Issues 反馈。觉得有用请给我们好评 ⭐

=== English Detailed Description ===

PinMate is an AI assistant for Pinterest creators. Upload an image and get an SEO title, detailed description, tagged topics, and alt text in seconds — then fill all Pinterest Create Pin fields with one click.

🚀 Core Features

• One-click generation — Analyzes the image on your Create Pin page and generates an SEO title, description, Tagged topics, and Alt Text in one click.
• AI-powered — Multimodal vision models understand the image's subject, style, and audience to produce engaging copy.
• Smart SEO — Titles and descriptions are infused with keywords and search intent to boost discovery and clicks.
• Auto-fill — Insert generated content directly into the correct Pinterest fields with one click.
• Multilingual — Switch UI between Chinese and English instantly, with separate analysis and output languages.
• Flexible panel — Draggable floating panel, show only on Create Pin or across all Pinterest pages.
• Privacy-first — Data stays local. Your API Key is stored only in browser extension storage.

📌 How to Use

1. Install PinMate, open the Pinterest Create Pin page, and upload an image.
2. Click the extension icon → Settings, choose an AI provider, and enter your API Key.
3. Click "Generate" on the floating panel, then "Fill All" to write the results into Pinterest.

🤖 Supports SiliconFlow, OpenAI, and any OpenAI-compatible endpoint.

⚠️ You need your own API Key from your chosen provider. PinMate does not include built-in keys.

🔒 Privacy Statement

PinMate does not collect personal data. Your API Key is stored locally, and image analysis and text generation are performed through the AI service you configure. PinMate never silently uploads your data.
