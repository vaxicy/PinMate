PinMate 是 Pinterest 内容创作者的 AI 助手。上传图片后，几秒内获得 SEO 标题、详细描述、话题标签与替代文本，一键填入 Pinterest 创建表单。

🚀 核心功能

• 一键生成 — 自动分析创建页图片，同时生成 SEO 标题、描述、Tagged topics 标签与 Alt Text。
• AI 驱动 — 多模态视觉模型理解图片主体、风格与受众，输出自然吸睛的文案。
• 智能 SEO — 标题与描述融入关键词与搜索场景，提升曝光与点击。
• 自动填入 — 生成内容一键写入 Pinterest 对应字段，无需复制粘贴。
• 多语言 — 分析与生成支持中英文实时切换。
• 灵活面板 — 悬浮面板支持全站显示或只在创建 Pin 页显示。
• 隐私优先 — 数据本地留存，API Key 仅保存在浏览器扩展存储中。

🤖 多家 AI 服务商 · 单 Key 直连

支持 SiliconFlow、OpenAI、Google Gemini 以及任意 OpenAI 兼容端点，每个 provider 独立保存 API Key、Base URL 与视觉模型；未列出的模型可一键切到自定义输入。
⚠ PinMate 不内置任何密钥，使用前请自带至少一个 provider 的 API Key。

📖 使用方法

1. 安装后打开 Pinterest 创建 Pin 页并上传图片。
2. 点击扩展图标 → 设置，选择 AI 服务商并填入你的 API Key 与模型，点「测试连接」验证。
3. 点悬浮面板「一键生成」，查看结果后「全部填入」即可。

🔒 隐私声明

PinMate 不收集个人数据。API Key 仅存本地，图片与文本生成通过你配置的 AI 服务完成，扩展不会静默上传数据。
