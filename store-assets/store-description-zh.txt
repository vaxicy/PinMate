PinMate 是 Pinterest 内容创作者的 AI 助手。上传图片后几秒内拿到 SEO 标题、描述、话题标签与替代文本，一键填入 Pinterest 创建表单。

🚀 核心功能
• 一键生成：自动分析创建页图片，输出 SEO 标题、描述、Tagged topics 与 Alt Text。
• AI 驱动：多模态视觉模型理解图片主体、风格与受众。
• 智能 SEO：标题与描述融入关键词与搜索场景，提升曝光。
• 自动填入：生成内容一键写入 Pinterest 字段，无需复制粘贴。
• 多语言：中英文界面与生成结果实时切换。
• 灵活面板：悬浮面板可全站显示或仅在创建 Pin 页显示。
• 隐私优先：数据本地留存，API Key 仅存扩展存储。

🤖 多家 AI 服务商 · Key 池与自动切换
支持 SiliconFlow、OpenAI、Google Gemini 与任意 OpenAI 兼容端点。每个 provider 独立保存多组 API Key、Base URL 与视觉模型；自动模式下 Key 失效无缝切换下一个，自带冷却避免重复试坏。
⚠ PinMate 不内置密钥，使用前请自备至少一个 provider 的 API Key。

📖 使用方法
1. 安装后打开 Pinterest 创建 Pin 页并上传图片。
2. 点击扩展图标 → 设置，选择 AI 服务商并填入 Key 与模型，点「测试连接」验证。
3. 点悬浮面板「一键生成」→ 查看结果 → 「全部填入」。

🔒 隐私声明
不收集个人数据。API Key 仅存本地，图片与文本生成通过你配置的 AI 服务完成，扩展不会静默上传。
